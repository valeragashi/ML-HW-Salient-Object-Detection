# Salient Object Detection (SOD)

An end-to-end Deep Learning project to segment prominent objects in images using a custom CNN.

## Performance Summary
* **Validation Accuracy:** 83.7%
* **Task:** Semantic Segmentation
* **Dataset:** 3,308 Image-Mask pairs

## Technical Architecture
* **Model:** Encoder-Decoder CNN
* **Parameters:** ~185k
* **Input Size:** 128x128

## Tech Stack
* **Language:** Python
* **Deep Learning:** TensorFlow / Keras
* **Development:** Google Colab & Git
